# 吴甜甜照片替换目录

把照片复制到本目录并使用下面的固定文件名，刷新页面即可自动替换占位图，无需修改代码。

| 文件名 | 用途 | 推荐比例 |
| --- | --- | --- |
| `hero.jpg` | 首页人物主照片 | 4:5 竖图 |
| `work.jpg` | 工作照片 | 4:5 竖图 |
| `life.jpg` | 日常生活照片 | 4:5 竖图 |
| `atmosphere.jpg` | 横版氛围照片 | 16:9 横图 |
| `gallery-01.jpg` | 照片墙 01 | 3:4 竖图 |
| `gallery-02.jpg` | 照片墙 02 | 1:1 方图 |
| `gallery-03.jpg` | 照片墙 03 | 4:3 横图 |

建议使用 JPG、sRGB 色彩空间，单张控制在 1.5MB 内。若文件不存在，页面会自动显示设计好的占位状态。
