## 重建可信度规则

- 爆炸图：可确认装配层级和大致空间关系，默认标记“结构展示级”。
- 单视图：只还原明确轮廓，厚度、背面结构必须标注估算。
- 双视图/三视图：按尺寸交叉校核，才可提升为“尺寸级重建”。
- CAD、STEP、SolidWorks：可进入工程级模型，不再用网页程序几何体代替。
- 材质判断必须同时参考零件名称、设备用途和图纸标注，不能只凭轮廓猜测。
- 每个零件先核对件号、中文名、英文名、页眉/总成、页码和单台用量，再进入3D建模。
- 扫描资料保留600dpi厂家原格；原PDF本身为矢量时，另保留裁切矢量PDF，禁止用AI重画替代厂家原图。

## 当前界面

- 先选择厂家资料，再在当前资料内搜索件号或名称。
- 支持“零件3D”、“总成3D”和“厂家原图”三种浏览方式。
- 3D预览每页6个，列表使用静态3D缩略图，详情只复用一个WebGL渲染器，避免手机连续开关后资源耗尽。
- 大模型旁显示件号、名称、所属总成、原手册页码、图纸尺寸和单台用量；件号可一键复制。
- 支持上一页、下一页和输入页码跳转。
- 卡片分别显示“资料已核/待核”和“轮廓3D/3D待核”，不再使用“真3D”“参数3D”等容易误解的说法。
- 未核图零件打开详情时默认展开厂家原页；录入的件号、名称和尺寸不得作为申报或采购依据。
- 已裁原格的零件在详情中默认显示厂家高清原格，并可打开矢量原格和原整页。
