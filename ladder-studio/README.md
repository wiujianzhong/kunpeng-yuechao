# 钢梯出图台

项目编号：LADDER-01。正式入口：https://wiujianzhong.github.io/kunpeng-yuechao/ladder-3d.html 。

本地主目录：当前目录。当前主文件：`index.html`，由`src/`源文件构建。

发布文件：`../ladder-3d.html`，由本目录`index.html`同步覆盖；用户要求沿用原网址。
旧版基线：Git提交`bf4495d`中2026-08-02发布的单台钢梯展示页，仅作为历史参考。

## 打开和使用

直接打开`index.html`即可使用，无需安装、登录或联网。该文件包含所有脚本和3D库。
只填地面到平台踩踏面的高度H，以及平台边缘垂直落地的点到梯脚A的水平距离L。可切换毫米或米。

其余参数默认采用此前项目确认的数据，均可展开修改。扶手默认500毫米，量法为踏板下坡前缘到扶手顶的垂直距离，并非通用推荐值。

排步算法比较相邻整数份数，以实际步高最接近目标250毫米为准。地面、每块踏板踩踏面和平台面共用等高步距，平台是最后一级，实体踏板数等于步距数减一。

## 输出

- 可旋转3D模型，正／侧／俯视观察和位置标注。
- 三视图SVG、CAD三视图DXF（真实毫米坐标）。
- 图片导出：当前角度的带标注3D、三视图、主梁扶手切口、踏板折弯、下料清单、安装定位表均可单独保存高清PNG。
- 主梁端切、立柱斜口、扶手端切、踏板折弯详图。
- 下料及定位CSV，打印／另存PDF。
- 保存整份方案：导出包含当前参数和完整程序的离线HTML，接收者可继续旋转、修改及打印。

## 制作约定

主梁在宽度方向两根对称，80侧面在竖向斜面，40窄面在上面。
踏板在两梁之间，水平、前后对中主梁侧面在该标高的水平接触范围。尺寸不允许完全接触时阻止施工文件导出。
立柱竖直，上下斜口同向，与主梁顶面、扶手底面准确相接，无显示补缝尺寸进入下料。
扶手两端竖直切齐，外包封板焊口磨圆；最上立柱上坡边对齐平台边缘。

折边高为成品外包高，板厚为基板厚。展开使用内圆角R和中性层系数K计算折弯扣除，属于试折参考，须用本厂刀具试折一块确认。
主梁和管材下料长按包围全部长点的毛料尺寸计算，锯缝不加进成品尺寸。

本工具进行几何和加工尺寸计算。平台／地面固定件、现场安装间隙及承载、焊缝和锚固验算不由两个输入推定，施工方需另行确认。

## 维护与核验

`node build.mjs`生成离线文件（复用本机已有esbuild和仓库Three.js，无新增依赖）。
`node --test tests/engine.test.mjs`验证排步、端切、坐标和参数联动。
`node tests/browser-check.mjs`验证真实Chrome页面、离线导出、手机布局、图纸导出与打印。

模型、图纸和清单全部引用`src/engine.mjs`计算结果，不维护多套尺寸。
