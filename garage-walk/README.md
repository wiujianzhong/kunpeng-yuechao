# 车库改造 · 自由漫游 Demo

原模型：车库改造_仓储规划_V3.blend（2026-08-31 19:12 保存，27 组货架）。

手机：点击进入漫游，左侧摇杆移动、右侧拖动视角。
电脑：W/A/S/D 移动、拖动转头、Shift 加速。
外围环绕自动旋转，拖动后转为手动旋转。俯视布局自动打开屋顶。
展示设置分别控制屋顶、外墙门窗、隔间墙、空间标注。显隐只影响观察，实体碰撞仍保留。
空间导航可快速进入指定区域，空间标注可点击查看。

本地预览：在本目录启动静态 HTTP 服务。所有运行资源均为同源本地文件，无第三方CDN依赖。

Three.js 与 Draco 第三方许可见 vendor 目录。
